# Godot AI Animation Toolkit 2.0.0

This release improves procedural humanoid motion, scene playback, and the
workflow from authoring to verification in the Godot editor. Compared with
v1.13.0, it adds updated Responsive motion defaults and expands checks around
saved clips, graph and modifier behavior, composition, and addon reload.

## What changed

- **Responsive motion.** Responsive is the default for newly generated
  humanoid motion. Grounded, Relaxed, Heavy, and Sneaky remain available.
  Updates include reach-aware jump planning, refined strafe and turn motion,
  and start/stop continuity. Existing saved clips remain intact.
- **Character setup and native playback.** Locomotion setup wires the
  AnimationTree and its grounding helper. Rig baking and secondary motion
  have expanded native playback checks. Sequences can combine supported 3D
  clips and saved poses with timed transitions and contact markers.
- **Editor workflow.** Ten families expose 103 operations. Eight are promoted
  as direct `custom_*` tools. Use `custom_manage` for
  `animation_sequence` and `animation_rig_modifiers`. Discovery,
  generation, history, save/reopen, and core reload are covered by release
  qualification.

## Compatibility and installation

Use **Godot 4.7.2** and **Godot AI 4.4.2 or later stable**. Release
qualification uses Godot AI 4.4.2 on Windows and Linux. Follow the
[installation instructions](https://github.com/michaltomczykowski/godot-ai-animation-toolkit/blob/v2.0.0/README.md#install)
and [migration guide](https://github.com/michaltomczykowski/godot-ai-animation-toolkit/blob/v2.0.0/docs/migration-2.0.0.md)
when upgrading a project.

**Known Linux issue.** An intermittent crash during scene save in stock
Godot 4.7.2 on Linux remains unresolved. The Windows and Linux clean-install
checks and the official Linux rendered-preview check passed.

The addon ZIP includes the toolkit and MIT license. Verify the ZIP against
the SHA-256 file and source manifest. The chaptered showcase is a separate
MP4 release asset. The source checkout includes an interactive Godot showcase
with the original Kite robot and editable examples. Private rigs and review
recordings are excluded from the release.
