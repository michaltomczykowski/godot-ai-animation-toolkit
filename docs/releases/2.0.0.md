# Godot AI Animation Toolkit 2.0.0

Release notes for the 2.0.0 candidate. Publication requires the exact-source
operation audit, independent visual assessment and supported installation matrix.

- Responsive is the default for newly generated humanoid motion. Grounded,
  relaxed, heavy and sneaky remain explicit styles. Existing saved clips are
  unchanged; regenerating them can change motion and timing.
- Ten registered animation families expose eight promoted `custom_*` tools.
  `animation_sequence` and `animation_rig_modifiers` use `custom_manage`.
- Public generation, native playback, scene history, save/reopen and core reload
  receive release qualification. Operation availability and limitations are
  recorded individually; scene Undo does not undo independent file writes.
- Requires Godot 4.7.2 and stable Godot AI >=4.2.1. Release qualification targets
  Windows/Linux with released cores 4.2.1 and 4.3.0; core main is advisory.
- ZIP installs contain the addon and MIT LICENSE. Assets include the ZIP's
  SHA256 checksum and an entry manifest identifying the committed source.

See [migration and limitations](../migration-2.0.0.md). Private rigs and review
footage are excluded from release assets.
