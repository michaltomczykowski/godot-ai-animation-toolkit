save/source evidence. ci_mcp_route.edit_gate already executes11 simple and9
remaining saved-scene native cases after the exact successful mcp_edit_audit

playback only, leaving valid_effect and track_paths_types unobserved. Enrich

scene; saved scene SHA256 and actual AnimationPlayer/clip/target binding; exact

public driver dependencies. Keep source contexts and all original requests.

track types, enabled/resolved targets and property value types. Recompute values
with independent source-specific constants/formulas; never trust an authored
expected echo, generated clip key interpolation, worst_error or mere change.
